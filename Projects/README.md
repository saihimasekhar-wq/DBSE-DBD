## 🏗️ System Architecture

The Pharmacy E-Commerce with Prescription Validation system follows a layered architecture consisting of the Users, Frontend, Backend/API, and Database layers.

Customers and administrators interact with the React.js web application through the Customer Interface and Admin Dashboard. The frontend communicates with the Node.js and Express.js REST API.

The backend manages authentication and authorization, medicine management, prescription management and validation, cart and order management, and inventory management. PostgreSQL is used to store and manage users, medicines, prescriptions, orders, order items, and inventory data.
